`monthly-template.xlsx` is a sanitized copy of the `BLANK` sheet in the
operator-supplied `Head Counts - FALL 2026.xlsx`. It retains the original styles,
column widths, merges, protection, validation, page setup and printer settings.
Other sheets and their sample attendance data are excluded; strings used by
BLANK are stored inline so unused shared strings are excluded too.

This is the fallback export layout when importing a legacy daily workbook.
A supplied monthly workbook is edited directly to preserve its other sheets.
